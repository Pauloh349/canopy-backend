### Why I started CANOPY

I wanted to build a student-focused platform that goes beyond simply sharing academic notes. I envisioned a platform where students can access learning resources, discover useful academic content, save materials, and eventually interact with a developer-friendly API that allows other applications to utilize CANOPY's resources.

I decided to call this project **CANOPY**.

I am starting from scratch, with Node.js as the backend foundation. Rather than rushing to build features, I want to understand how a production-ready platform is designed, developed, secured, tested and deployed.

This project is also a learning journey. I want to improve my backend engineering skills by writing the code myself, understanding the decisions I make, and documenting the challenges I encounter along the way.
